공을 중앙으로 되돌리는 판단을 SNN 회로로 표현하기

이 프로젝트는 30×30cm 보드 위 공을 중앙 반경 1cm 안으로 이동시키는 BallControl 과제에서 시작했습니다. 공의 위치와 무게를 스파이크 입력으로 표현하고, LIF 뉴런이 시간에 따라 상태를 누적해 X·Y 네 방향의 제어 이벤트를 만드는 구조를 설계했습니다. 핵심은 완성 장치의 외형이 아니라 물리 문제를 신호와 상태 전이로 바꾸는 과정이었습니다.

무엇을 만든 프로젝트인가

최종 발표의 네트워크는 99개 위치 입력, 32개 은닉 뉴런, 4개 방향 출력 뉴런으로 구성됩니다. 위치는 좌표 하나만 활성화하는 one-hot 방식으로, 공의 무게는 일정 시간 동안 발생하는 spike rate로 표현했습니다. 네 출력의 spike 수를 세어 +X, −X, +Y, −Y 방향의 제어량으로 해석했습니다.

문제
보드 위 공을 중앙 목표 영역으로 이동
구조
99 input → 32 hidden → 4 output
언어·도구
Verilog · Vivado 2025.1 · 기능 시뮬레이션
담당
팀장 · 과제 해석 · SNN/LIF 조사 · 통합과 결과 정리

위치와 무게가 네 방향 출력이 되기까지

최종 발표자료의 흐름을 구현 관점에서 다시 정리하면 다음과 같습니다. 위치와 무게는 같은 종류의 입력이 아닙니다. 위치는 어느 좌표가 활성화됐는지를 나타내고, 무게는 같은 자극이 시간축에서 얼마나 자주 반복되는지를 바꿉니다.

01 · 입력 표현 X·Y 위치와 공의 무게 보드 좌표와 15g·30g 조건
02 · 위치 부호화 11×9 one-hot 99개 중 현재 좌표 하나를 활성화
03 · 상태 계산 32개 LIF 뉴런 흥분·억제 가중치와 막전위 갱신
04 · 방향 출력 4개 LIF 뉴런 +X · −X · +Y · −Y
05 · 출력 해석 방향별 spike count 모터가 반응할 방향과 크기로 변환

위 99→32→4 구조는 최종 발표의 네트워크 기준입니다. 저장소에 둔 Verilog 세 파일은 이 전체 실험망을 재현하는 실행 패키지가 아니라, 네 방향 출력 제어의 인터페이스를 설명하는 선별 코드입니다.

설계 구상, 코드, 검증 범위를 구분했습니다

최종 발표에서 설명한 구조

99→32→4 SNN과 시간 단계 제어

위치 one-hot 입력, 32개 은닉 뉴런, 4개 방향 출력, spike count decoding과 실행 FSM을 발표자료에서 확인했습니다.

보관 코드에서 확인한 구조

오차 분리와 4채널 LIF 출력

error_encoder, lif_neuron, controller_top은 signed X·Y 오차가 네 방향 1-bit 이벤트가 되는 경로를 보여줍니다.

실험으로 확인한 내용

무게에 따른 rate encoding 변화

15g와 30g을 서로 다른 digital weight로 바꾸고, 다섯 개 초기 위치에서 spike 수와 위치 변화가 달라지는지 시뮬레이션했습니다.

확인하지 않은 내용

물리 센서·모터 폐루프

카메라 위치 추정, 실제 모터 구동 파형, 기구부 응답과 중앙 반경 1cm 도달 여부를 연결한 보드 실험 자료는 남아 있지 않습니다.

해석 경계: 발표자료의 이동 경로는 SNN/제어 모델의 시뮬레이션 결과입니다. 실제 공이 보드 위에서 같은 경로로 움직였다는 물리 실험 결과로 확대해서 설명하지 않습니다.

합성 표에는 LUT 10개, FF 41개, DSP와 BRAM 0개가 기재되어 있습니다. I/O는 83개로 별도 집계되며 사용률이 99.85%입니다. 전력 2.302W도 보드에서 측정한 값이 아니라 Vivado 추정값이고, 그중 I/O가 1.968W로 대부분을 차지합니다. 따라서 이 수치들은 작은 내부 로직과 넓은 top-level 인터페이스를 보여주는 자료로 읽는 것이 적절합니다.
