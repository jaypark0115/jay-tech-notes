경진대회 프로젝트 요약 노트

제가 참여한 두 경진대회에서 진행한 프로젝트의 목표와 수행 범위, 사용한 기술, 확인한 결과를 간단히 정리했습니다.

2025 · 팀 반짝반짝

SNN BallControl 출력 제어 회로

30×30cm 보드 위 공의 위치와 속도를 읽어 중앙으로 이동시키는 과제를 SNN 출력 제어 회로로 구현했습니다. signed X/Y 오차를 네 방향 크기로 바꾸고, 각 방향의 LIF 뉴런이 모터 제어 스파이크를 생성합니다.

공의 X·Y 위치
속도 크기 → 방향별 오차
encoder → 4채널
LIF 뉴런 → X/Y 모터
네 방향 신호
수행 내용
SNN/LIF 조사, 요구사항 해석, output-layer RTL 구조, 입력 방식 실험, 팀 일정과 발표자료 정리
핵심 기술
Signed error encoding, LIF neuron, rate encoding, Verilog RTL hierarchy
구현 범위
공의 상태 입력을 네 방향 모터 스파이크로 변환하는 출력 제어 파이프라인
확인 결과
입력 방식 비교, RTL 동작, 합성 자원과 I/O 사용량, Vivado 전력 추정
3편의 기술 글
1. BallControl 문제와 회로 구조 2. Encoder와 LIF RTL 신호 흐름 3. 입력 실험과 구현 결과
2026 · 팀 경이원지

YOLOv2 Full-Graph FPGA 가속기

학습된 YOLOv2를 INT8 중심의 정수 연산으로 바꾸고, Conv·Pool·Route·Upsample과 두 detection head를 포함한 전체 그래프를 FPGA에서 실행했습니다. 대표 이미지 양자화 실험부터 229장 보드 검증까지 하나의 흐름으로 연결했습니다.

입력 이미지
학습 weights → INT8 저장
INT32 누산 → 22단계
FPGA 연산 → 두 detection
head → 객체 위치와
종류
수행 내용
양자화 조건 탐색, 정수 모델–RTL 연결, full-graph 통합과 병목 개선, FPGA 보드 검증
핵심 기술
INT8/INT32 data path, requantization, descriptor scheduling, DDR workspace, 144-lane MAC
구현 범위
22개 처리 단계와 두 detection head를 포함한 YOLOv2 전체 그래프의 FPGA 실행
최종 검증
229/229 PASS, 11.420687 compute-only FPS, 78.60% detector mAP
3편의 기술 글
1. INT8 양자화와 requantization 2. Full-graph FPGA 아키텍처 3. 229장 보드 검증과 결과
