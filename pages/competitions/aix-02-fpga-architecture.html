2. YOLOv2 Full-Graph FPGA 구조

Full-graph 가속기는 서로 다른 크기의 feature map과 분기 경로를 정해진 순서와 주소로 연결한다. DDR은 공용 workspace이며, 22개 descriptor가 Conv·Pool·Route·Upsample과 두 detection head의 실행을 제어한다.

최종 구현 사양

Nexys 4 DDR의 Artix-7은 100MHz로 동작하며, JTAG-to-AXI가 host와 DDR을 연결한다. FPGA 내부는 144개 packed MAC lane, layer descriptor ROM, weight cache, feature buffer, scheduler로 구성된다.

Host–FPGA 역할

host는 bitstream program, 입력 전처리, weight·input DDR preload, 시작 명령, 완료 polling을 수행한다. FPGA scheduler는 layer descriptor를 따라 22개 단계를 실행하고 두 detection head를 DDR에 기록한다. host는 두 출력을 읽어 box decode, class score, NMS를 수행한다.

DDR workspace와 두 detection head

전역 workspace는 feature map 주소 구간을 재사용한다. Route가 다시 읽는 feature map과 두 detection head 출력은 별도 주소에 보존한다. 하나의 32-bit word에는 8-bit HWC 값 네 개가 저장된다.

22개 layer descriptor

144-lane packed MAC

144는 3×3 kernel과 16개 입력 channel을 한 묶음으로 처리하는 3×3×16 구조에서 나옵니다. packed-pair DSP 경로는 하나의 weight와 두 activation을 공유해 두 spatial dot product를 계산한다. 1×1 convolution에서는 필요한 lane group만 활성화해 같은 array를 재사용한다.

3×3×16한 channel tile의 곱셈 항
2×144Accepted cycle의 구조적 scalar products
205 / 240최종 설계 전체 DSP

2×144는 packed datapath가 만드는 구조적 연산 수입니다. descriptor 전환, DDR 대기, Pool·Route·Upsample과 write-back까지 포함한 지속 처리량은 최종 cycle counter로 평가한다.
