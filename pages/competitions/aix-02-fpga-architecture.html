2. YOLOv2 전체 그래프를 FPGA 안에서 이어 가는 구조

Full-graph 가속기에서 어려운 점은 MAC array 하나를 빠르게 만드는 것이 아니라, 서로 다른 크기의 feature map과 분기 경로를 올바른 순서와 주소로 연결하는 것입니다. 이 설계는 DDR을 공용 workspace로 사용하고, 22개 descriptor가 Conv·Pool·Route·Upsample과 두 detection head의 실행을 제어합니다.

최종 구현 사양

Nexys 4 DDR의 Artix-7을 100MHz로 동작시키고, JTAG-to-AXI로 host와 DDR을 연결했습니다. FPGA 내부에서는 144개 packed MAC lane, layer descriptor ROM, weight cache와 feature buffer가 하나의 scheduler 아래에서 동작합니다.

Host는 준비와 평가를, FPGA는 정수 full graph를 맡습니다

host는 bitstream program, 입력 전처리, weight와 input의 DDR preload, 시작 명령과 완료 polling을 담당합니다. FPGA scheduler는 layer descriptor를 따라 22개 단계를 실행하고 두 detection head를 DDR에 기록합니다. host는 두 출력을 읽어 box decode, class score와 NMS를 수행합니다.

DDR workspace가 분기와 두 detection head를 연결합니다

feature map을 layer마다 새 공간에 계속 쌓으면 DDR 용량과 주소 관리가 커집니다. 이 설계는 전역 workspace의 주소 구간을 재사용하고, Route가 다시 읽어야 하는 feature map과 두 detection head의 출력은 필요한 시점까지 별도 주소에 보존합니다. 한 32-bit word에는 8-bit HWC 값 네 개를 묶습니다.

22개 descriptor는 연산기 수가 아니라 실행 순서입니다

descriptor ROM에는 각 단계의 연산 종류, 입력·출력 shape, DDR 주소, kernel과 stride, activation과 requantization 조건이 들어 있습니다. scheduler는 같은 compute block을 재사용하면서 descriptor만 바꿔 전체 그래프를 진행합니다.

144-lane packed MAC을 3×3과 1×1 경로에서 재사용합니다

144는 3×3 kernel과 16개 입력 channel을 한 묶음으로 처리하는 3×3×16 구조에서 나옵니다. packed-pair DSP 경로는 하나의 weight와 두 activation을 공유해 두 spatial dot product를 계산합니다. 1×1 convolution에서는 필요한 lane group만 활성화해 같은 array를 재사용합니다.

205 / 240최종 설계 전체 DSP

2×144는 packed datapath가 만드는 구조적 연산 수입니다. descriptor 전환, DDR 대기, Pool·Route·Upsample과 write-back까지 포함한 지속 처리량은 최종 cycle counter로 평가했습니다.
