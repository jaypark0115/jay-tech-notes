두 경진대회에서 무엇을 만들었나

한 프로젝트에서는 보드 위 공의 위치를 읽어 네 방향 제어 신호를 만드는 SNN 회로를 다뤘고, 다른 프로젝트에서는 YOLOv2 객체검출 모델 전체를 FPGA에서 실행하는 가속기를 다뤘습니다. 사용하는 알고리즘은 다르지만, 두 작업 모두 소프트웨어의 계산 방법을 실제 하드웨어가 처리할 수 있는 데이터 흐름으로 바꾸는 과정이 중심입니다.

공을 중앙으로 움직이는 SNN 제어 회로

2025 전국 대학생 AI 반도체 회로 설계 경진대회는 두 단계로 진행됐습니다. 첫 단계에서는 스파이킹 뉴럴 네트워크(SNN)와 LIF 뉴런의 동작을 조사했고, 다음 단계에서는 그 개념을 BallControl 문제에 적용했습니다. BallControl은 30×30cm 보드 위에 놓인 공의 위치와 움직임을 바탕으로, 공이 중앙으로 향하도록 모터 방향을 정하는 과제입니다.

공의 X·Y 위치
속도 크기 → 방향별 오차
encoder → 4채널
LIF 뉴런 → X/Y 모터
네 방향 신호

이 글묶음에서 설명하는 실제 구현 범위는 센서와 기구부를 모두 포함한 완성형 폐루프 장치가 아니라, 위치·속도 값을 받아 네 방향 스파이크를 만드는 출력 제어 회로입니다. 첫 글은 문제를 회로 사양으로 바꾸는 과정을, 둘째 글은 RTL 데이터 흐름을, 셋째 글은 입력 방식의 변화와 구현 결과를 설명합니다.

이 프로젝트에서 한 일

  • SNN과 LIF 뉴런의 디지털 하드웨어 구현 사례를 조사했습니다.
  • 공의 위치·속도·무게 조건을 회로 입력과 네 방향 출력으로 해석했습니다.
  • 오차 encoder, 4채널 LIF와 top-level을 잇는 출력 계층 RTL 구조를 정리했습니다.
  • 위치 기반 입력과 무게 반영 rate encoding을 비교하고 결과 자료를 팀장으로 통합했습니다.

사용한 기술 개념

  • LIF neuron: 입력을 막전위에 누적하고 임계값에서 스파이크를 만드는 상태 기반 뉴런
  • Rate encoding: 물리량의 크기를 일정 시간 동안 발생하는 스파이크 빈도로 표현하는 방법
  • Signed error encoding: X·Y 오차의 부호와 크기를 네 방향의 양수 채널로 바꾸는 방법
  • RTL hierarchy: encoder, neuron, top 모듈의 역할과 클록 단위 상태 변화를 명시하는 설계

YOLOv2 객체검출 모델을 실행하는 FPGA 가속기

AIX 2026 Deep Learning Hardware 설계경진대회에서는 학습된 YOLOv2 모델을 FPGA 보드에서 동작시키는 가속기를 만들었습니다. YOLOv2는 이미지에서 물체의 위치와 종류를 찾는 신경망입니다. 부동소수점 모델을 그대로 옮기는 대신 정수 양자화를 적용하고, convolution뿐 아니라 pooling, route, upsample과 두 개의 detection head까지 전체 계산 흐름을 하드웨어에서 이어야 했습니다.

입력 이미지
학습 weights → INT8
양자화 → 22단계
FPGA 연산 → 두 detection
head → 물체 위치와
종류

첫 글은 모델 값을 하드웨어용 정수로 바꾸면서 정확도를 확인한 방법을, 둘째 글은 모델 전체가 FPGA와 DDR 안에서 실행되는 구조를, 셋째 글은 한 장 테스트를 229장 평가로 확장해 속도와 검출 정확도를 확인한 과정을 설명합니다.

이 프로젝트에서 한 일

  • 대표 이미지와 detector mAP를 이용해 layer별 양자화 조건을 탐색했습니다.
  • 정수 소프트웨어 모델의 배율·반올림 규칙을 RTL 데이터 경로와 연결했습니다.
  • 22단계 full graph의 RTL 통합과 DDR·연산 병목 개선에 참여했습니다.
  • FPGA 보드에서 한 장 테스트를 229장 평가로 확장하고 최종 결과를 정리했습니다.

사용한 기술 개념

  • Post-training quantization: 학습된 모델을 대표 입력으로 보정해 정수 연산으로 바꾸는 방법
  • INT8 MAC·INT32 accumulation: 저장과 곱셈은 작게, 여러 곱의 합은 넓게 유지하는 데이터 경로
  • Graph-aware scheduling: Conv 외의 Route와 Upsample까지 descriptor로 실행하는 제어 구조
  • Memory hierarchy: DDR, cache와 buffer 사이의 데이터 이동을 연산 속도와 함께 설계하는 방법
  • Two-head validation: 서로 다른 해상도의 두 검출 출력을 함께 후처리해 detector mAP를 확인하는 검증
