LED 모션캡처 기반 드론 비행경로 제어 시스템

실내의 여러 적외선 카메라로 드론에 부착한 LED 마커를 추적해 3차원 위치와 자세를 실시간으로 계산하고, 사용자가 입력한 목표 경로를 드론이 따라가도록 제어하는 시스템을 구현하고 있습니다. 스마트폰에서는 목표 경로를 입력하고 실제 비행 경로와 결과를 확인할 수 있도록 구성할 예정입니다.

현재 목표 2026년 10월 10일까지 졸업논문과 학술대회 제출용 결과를 정리하고, 종합설계 일정에 따라 11월 최종 제작·발표·보고서 제출까지 이어갑니다.
참여 인원 박재연 외 2명(조원 1, 조원 2)이 함께 진행하는 프로젝트입니다.

1. 연구 주제와 목표

종합설계 제안서의 주제는 ‘모션캡처 시스템을 활용한 드론의 궤적 추종 제어 시스템’입니다. 상용 모션캡처 장비보다 접근하기 쉬운 비전 센서와 임베디드 연산 장치를 조합해 실내 정밀 측위 및 제어 환경을 직접 구축하는 것이 핵심입니다.

안전망이 설치된 실내 공간에서 영상 입력, 3차원 위치·자세 추정, 궤적 오차 계산, 제어 명령 전달을 하나의 폐루프 시스템으로 연결하는 것을 최종 목표로 합니다. 중앙대학교 전자전기공학부 제어 및 로봇 SLAM 연구실을 운영하는 심덕선 교수님의 지도 아래 진행하고 있습니다.

2. 시스템 구성

Vision

적외선 카메라 4대

실내 공간의 여러 방향에서 드론의 IR LED 마커를 촬영합니다.

Marker

드론 IR LED

카메라 영상에서 구분 가능한 기준점으로 사용해 위치와 자세를 추정합니다.

Compute

Jetson Orin Nano

다채널 영상을 처리하고 3차원 위치·자세와 궤적 오차를 실시간 계산합니다.

Interface

스마트폰 웹 앱

목표 비행 경로를 입력하고 실제 이동 경로와 결과를 확인하는 UI를 제공합니다.

보유 장비

시스템 구축에 사용할 Jetson Orin Nano와 카메라 어레이는 박재연이 소유하고 있으며, 이를 기반으로 영상 수집과 실시간 경로 추정 환경을 구성할 예정입니다.

3. 담당 역할과 검증 방법

프로젝트에서 IR LED와 카메라 모듈을 이용해 드론의 이동 경로를 추정하는 프로그램 제작을 담당하고 있습니다. 여러 카메라의 관측값으로 위치를 계산하고, 제어 시스템이 사용할 수 있는 경로 데이터로 전달하는 부분을 구현합니다.

Ground Truth 검증

드론 또는 IR LED 표적을 산업용 로봇팔이나 리니어 모터에 고정하고, 장비에 입력한 정밀 기준 경로와 모션캡처가 추정한 3차원 경로를 비교합니다. 이 과정으로 정적·동적 위치 정확도와 반복 정밀도를 평가한 뒤 실제 드론의 폐루프 궤적 추종 비행으로 확장합니다.

4. 개발 일정

종합설계 제안서의 7~11월 일정표를 공개용 진행 단계로 간단히 정리했습니다.

7월

요구사항 분석·시스템 설계

필요 기능, 블록 구성, 시스템 사양과 실험 환경을 확정합니다.

7~8월

경로 추정·드론 기체 제작

IR LED·카메라 기반 경로 추정 프로그램과 실험용 드론 기체를 제작합니다.

8~9월

원격 제어·앱 연동

드론 원격 제어와 스마트폰 경로 입력 앱을 연결하고 시스템을 통합합니다.

9~10월

Ground Truth 실험·보완

정확도와 반복 정밀도를 측정하고 궤적 추정 및 제어 기능을 보완합니다.

10~11월

최종 제작·발표

전체 시스템을 완성하고 최종보고서, 시연과 발표 결과를 정리합니다.

5. 완성 목표

사용자가 스마트폰으로 입력한 목표 경로와 실제 드론 경로의 차이를 정량적으로 확인하고, 실내 안전 환경에서 안정적인 궤적 추종 비행을 재현하는 것이 목표입니다. 졸업논문과 학술대회 제출 결과를 먼저 정리한 뒤 종합설계 최종 제작과 제품·연구 확장 가능성까지 검토할 예정입니다.
