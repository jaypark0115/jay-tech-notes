1. BallControl 입력 표현과 출력 정의

BallControl 제어 모델은 연속적인 물리 상태를 이산 입력으로 변환한다. 위치는 현재 좌표를, 무게는 시간축 자극의 크기를 나타낸다. 두 값은 one-hot 위치 입력과 rate encoding으로 서로 다르게 표현된다.

입력·출력 사양

30×30cm 보드의 위치는 99개 입력 뉴런으로 표현된다. 1~30g 무게는 시간축 spike 수에 반영되며, 출력 계층은 네 방향 제어 신호를 제공한다.

보드
30×30cm
공 무게
1~30g
목표
중앙 반경 1cm
출력
+X · −X · +Y · −Y

과제 조건과 좌표 모델

좌표계의 중심은 (0, 0)이며, X축은 −5부터 +5, Y축은 −4부터 +4까지의 격자로 모델링된다. 11×9 격자는 99개 입력 뉴런에 대응한다. 중앙 반경 1cm는 제어 목표의 물리 기준으로 사용된다.

물리 조건회로에서의 표현설계 의미
30×30cm 보드11×9 위치 격자연속 좌표를 99개 이산 위치로 단순화
중앙 목표(0, 0)부호가 방향, 절댓값이 중앙과의 거리
중앙 반경 1cm출력 종료 조건의 물리 기준실물 센서 오차까지 포함한 검증은 별도 필요
공 무게 1~30gdigital weight와 spike rate무거운 공에 더 큰 시간축 자극 부여
보드 기울임네 방향 출력 뉴런+X·−X·+Y·−Y 제어 이벤트로 분리

좌표 격자와 무게 입력은 제어 문제를 시험하기 위한 모델이다. 카메라가 실제 좌표를 어떻게 추정하는지, 센서 노이즈를 어떻게 보정하는지는 이번 회로의 입력 앞단에 놓이는 별도 문제입니다.

위치 one-hot 부호화

X축 11개와 Y축 9개의 조합은 99개 위치를 만든다. 현재 좌표에 해당하는 입력 뉴런 하나만 활성화되며, 네트워크는 활성 위치를 one-hot 벡터로 수신한다. 위치별 흥분·억제 가중치는 이 입력 벡터에 연결된다.

좌표 (x, y) x∈[−5,5], y∈[−4,4]
주소 계산 11×9 격자 index 현재 좌표의 뉴런 번호 선택
입력 벡터 99-bit one-hot 선택한 위치만 1
네트워크 99→32 연결 위치별 흥분·억제 가중치 적용

예를 들어 공이 (+3, +4)에 있으면 해당 위치 뉴런이 활성화된다. 중앙 방향에 해당하는 −X와 −Y 경로는 출력 뉴런의 막전위 누적에 기여한다. spike 출력은 모터 구동 파형이 아니라 방향 이벤트이다.

무게 rate encoding

one-shot 입력은 위치 정보만 전달한다. 무게 조건은 정해진 시간 창에서 counter < weight일 때 spike를 발생시키는 rate encoding으로 표현된다. digital weight가 클수록 입력 이벤트 수가 증가한다.

위치 입력

공간 정보를 표현

99개 중 하나가 활성화되어 현재 공이 어느 격자에 있는지를 나타냅니다.

무게 입력

시간축 자극의 양을 조절

15g에는 digital weight 123, 30g에는 255를 적용한다.

123과 255는 센서 교정식이 아닌 시뮬레이션 입력값이다. 중간 무게에 대한 선형성이나 실제 구동력은 이 값만으로 정의되지 않는다.

방향 출력 정의

출력 계층은 +X, −X, +Y, −Y 네 채널로 구성된다. 같은 시간 창의 방향별 spike 수를 집계하고, 서로 반대인 채널의 차이를 X축과 Y축 제어량으로 변환한다. 파형에서는 출력 채널과 제어 방향의 대응을 직접 확인할 수 있다.

출력 뉴런의미중앙으로 복귀하는 예
+XX축 양의 방향 제어 이벤트공이 중앙의 왼쪽에 있을 때 증가
−XX축 음의 방향 제어 이벤트공이 중앙의 오른쪽에 있을 때 증가
+YY축 양의 방향 제어 이벤트공이 중앙의 아래쪽에 있을 때 증가
−YY축 음의 방향 제어 이벤트공이 중앙의 위쪽에 있을 때 증가

다음 글에서는 이 입력이 LIF 막전위, 실행 FSM과 네 방향 출력 Verilog로 어떻게 이어지는지 살펴봅니다.
