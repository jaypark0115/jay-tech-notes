SNN 기반 BallControl 제어 회로

BallControl 과제는 30×30cm 보드 위 공을 중앙 반경 1cm 안으로 이동시키는 제어 문제이다. 공의 위치와 무게는 spike 입력으로 표현되며, LIF 뉴런은 시간에 따른 상태 누적을 통해 X·Y 네 방향의 제어 이벤트를 생성한다. 문서는 물리 조건, 신호 표현, SNN 구조, 시뮬레이션 및 합성 결과를 다룬다.

프로젝트 개요

최종 발표의 네트워크는 99개 위치 입력, 32개 은닉 뉴런, 4개 방향 출력 뉴런으로 구성된다. 위치는 좌표 하나만 활성화하는 one-hot 방식으로, 공의 무게는 일정 시간 동안 발생하는 spike rate로 표현된다. 네 출력의 spike 수는 +X, −X, +Y, −Y 방향의 제어량으로 변환된다.

시스템 구성

위치와 무게는 서로 다른 입력 속성을 가진다. 위치는 활성화된 좌표를 나타내며, 무게는 시간축의 spike 발생 빈도를 조절한다. 전체 경로는 입력 표현, 계층별 상태 계산, 방향별 출력 해석으로 구성된다.

01 · 입력 표현 X·Y 위치와 공의 무게 보드 좌표와 15g·30g 조건
02 · 위치 부호화 11×9 one-hot 99개 중 현재 좌표 하나를 활성화
03 · 상태 계산 32개 LIF 뉴런 흥분·억제 가중치와 막전위 갱신
04 · 방향 출력 4개 LIF 뉴런 +X · −X · +Y · −Y
05 · 출력 해석 방향별 spike count 모터가 반응할 방향과 크기로 변환

99→32→4 구조는 최종 발표의 네트워크 기준이다. 저장소의 Verilog 세 파일은 전체 실험망이 아닌 네 방향 출력 제어 인터페이스를 다루는 참고 모듈이다.

구현 범위와 검증 경계

발표자료 기준 구조

99→32→4 SNN과 시간 단계 제어

위치 one-hot 입력, 32개 은닉 뉴런, 4개 방향 출력, spike count decoding과 실행 FSM을 포함한다.

참고 RTL 모듈

오차 분리와 4채널 LIF 출력

error_encoder, lif_neuron, controller_top은 signed X·Y 오차가 네 방향 1-bit 이벤트가 되는 경로를 보여준다.

기능 시뮬레이션

무게에 따른 rate encoding 변화

15g와 30g을 서로 다른 digital weight로 바꾸고, 다섯 개 초기 위치별 spike 수와 위치 변화를 기록한다.

검증 대상 외 항목

물리 센서·모터 폐루프

카메라 위치 추정, 실제 모터 구동 파형, 기구부 응답과 중앙 반경 1cm 도달 여부를 연결한 보드 실험 자료는 포함하지 않는다.

해석 경계: 발표자료의 이동 경로는 SNN/제어 모델의 시뮬레이션 결과이다. 실제 공이 보드 위에서 같은 경로로 움직였다는 물리 실험 결과는 포함하지 않는다.

담당 범위

요구사항 해석

물리 조건과 회로 입출력

보드 크기, 목표 영역, 위치와 무게 조건을 뉴런 입력과 출력 사양으로 문서화한다.

기술 조사

LIF와 spike encoding

LIF 뉴런, one-hot 위치 입력, rate encoding의 제어 의미와 적용 조건을 정리한다.

RTL 통합

입력·뉴런·출력 인터페이스

모듈별 입출력 의미와 시뮬레이션 결과를 동일한 신호 정의로 연결한다.

검증 경계

시뮬레이션과 물리 제어의 차이

방향 이벤트 생성은 RTL·시뮬레이션 범위이며, 실제 장치의 안정화는 센서·모터·기구부를 포함한 별도 검증 범위이다.
