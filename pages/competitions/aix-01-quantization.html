1. YOLOv2를 FPGA가 실행할 수 있는 정수 연산으로 바꾸기

양자화의 목표는 tensor 값 몇 개를 비슷하게 만드는 것이 아니라, 두 detection head가 최종적으로 비슷한 박스와 class를 내도록 하는 것이었습니다. 대표 이미지에서 layer별 값의 범위를 관찰하고 scale 후보를 만든 뒤, detector mAP가 개선되는 후보만 최종 설정에 반영했습니다.

대표 이미지로 범위를 보고, 전체 검출 정확도로 후보를 골랐습니다

calibration 이미지를 정수 모델에 통과시키며 layer별 activation과 weight 분포를 수집했습니다. 극단값을 모두 보존하면 대부분의 값이 좁은 정수 구간에 몰릴 수 있고, 반대로 범위를 너무 좁히면 saturation이 늘어납니다. 분포는 후보를 만드는 근거로 사용하고, 최종 선택은 detector mAP로 확인했습니다.

위 값은 최종 scale 파일의 대표 layer입니다. 전체 layer에 하나의 전역 scale을 쓰지 않았고, “큰 multiplier가 더 정확하다”는 식으로 단일 숫자를 비교하지 않았습니다.

저장은 8-bit로 줄이고, 누산은 32-bit로 보호했습니다

feature map과 weight를 8-bit로 저장해 DDR와 BRAM 이동량을 줄이되, 여러 곱셈 결과가 더해지는 convolution accumulator는 32-bit를 사용했습니다. layer 출력은 bias와 활성화를 적용한 뒤 고정소수점 multiplier와 shift로 다시 8-bit 범위에 맞춥니다.

Detection head

Signed 8-bit 출력

box와 class logit에 필요한 음수 값을 보존하기 위해 ReLU를 우회하고 −128~127로 제한했습니다.

Requantization은 다음 layer와의 인터페이스입니다

INT32 누산 결과를 그대로 DDR에 저장하면 메모리 사용량과 다음 연산의 입력 형식이 모두 달라집니다. 각 layer에 정해진 multiplier를 곱하고, round offset을 반영한 뒤 오른쪽 shift와 signed/unsigned clamp를 수행해 다시 8-bit feature map을 만듭니다.

예: CONV00

18,432가 8-bit 값 69가 되는 과정

최종 계수는 mul=1,006,507, shift=28, round=0입니다. 18,432×1,006,507을 28-bit 오른쪽 shift하면 69가 되고, unsigned clamp 뒤에도 69가 유지됩니다.

Rounding 규칙

모든 layer에 같은 반올림을 가정하지 않았습니다

CONV00은 round offset이 0이라 양수는 shift 과정에서 잘립니다. signed 음수는 절댓값을 shift한 뒤 부호를 복원하고 최종 범위로 제한합니다.

양자화된 software reference는 83.60% mAP를 기록했습니다

83.60%는 FPGA 결과가 아니라 최종 정수 계수를 사용하는 software reference의 detector mAP입니다. FPGA 결과 78.60%와 비교할 때 기준점이 됩니다. 즉 float 모델과 정수 모델의 차이, 정수 모델과 FPGA 실행의 차이를 한 단계로 섞지 않고 나눠 볼 수 있습니다.
