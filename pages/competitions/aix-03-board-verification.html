3. 한 장의 시연에서 229장 detector 검증까지

최종 검증은 simulation PASS나 한 장의 검출 이미지로 끝내지 않았다. test_one으로 program, preload, compute, readback과 후처리 경로를 먼저 확인한 뒤, 한 번의 Vivado hardware session에서 229장을 순차 실행하는 test_all로 확장했다. 마지막 acceptance criterion은 두 detection head를 사용한 detector-level mAP였다.

시간 기준 11.420687 FPS는 100MHz cycle counter로 계산한 FPGA compute-only 수치다. bitstream program, JTAG 전송과 host 후처리가 포함된 전체 실행 시간과 구분한다.

3.1 test_one으로 전체 실행 경로를 한 단계씩 확인했다

  1. Program: Vivado batch/Tcl로 최종 bitstream을 FPGA에 올린다.
  2. Preload: JTAG-to-AXI로 weights와 입력 tensor를 DDR에 기록한다.
  3. Compute: control register를 통해 full graph 실행을 시작하고 done/cycle을 읽는다.
  4. Readback: DDR에서 8×8 CONV14와 16×16 CONV20 결과를 모두 읽는다.
  5. Postprocess: 두 head를 decode하고 NMS를 적용해 bounding box와 비교 이미지를 만든다.
  6. Cooldown: 실행 후 blank bitstream을 올려 장시간 테스트 사이의 보드 상태를 관리한다.

3.2 test_all은 229장을 같은 hardware session에서 실행했다

매 이미지마다 bitstream과 weights를 다시 올리면 순수 계산 성능과 JTAG 준비 시간이 섞인다. 최종 runner는 bitstream program과 weight preload를 한 번 수행하고, 229개 입력을 순차 교체하며 compute cycle과 두 head 출력을 저장했다. 모든 이미지가 끝난 뒤 저장된 FPGA 출력을 같은 detector evaluator로 평가했다.

3.4 성능 개선 과정에서 acceptance criterion을 잃지 않았다

개발 중 가장 위험한 경우는 빠른 bitstream이 정상처럼 보이지만 detector 전체를 계산하지 않는 상황이었다. CONV20-only smoke build는 속도 확인에는 유용했지만 작은 물체를 담당하는 CONV14가 빠져 최종 mAP 기준으로 사용할 수 없었다. 그래서 최종 결과는 두 head의 존재, 229장 completion, detector mAP, timing closure를 동시에 만족할 때만 채택했다.

  • tensor mismatch는 최초 오차 layer와 fixed-point domain을 찾는 진단 도구로 사용했다.
  • Route/Upsample의 layout과 DDR offset을 descriptor와 readback 결과로 교차 확인했다.
  • MAC 병렬도 증가 뒤에는 DSP 수뿐 아니라 routing과 requant timing을 다시 확인했다.
  • 중간 성능 숫자는 버리고 최종 full-detector bitstream의 결과만 보고했다.

3.5 프로젝트에서 수행한 범위와 남긴 결과

이 프로젝트에서 수행한 작업은 소프트웨어 양자화 조건 탐색, 정수 도메인과 RTL datapath의 연결, full-graph scheduler와 accelerator 통합·최적화, 실제 FPGA 보드 검증, 최종 실행 패키지 정리로 요약할 수 있다. 팀 프로젝트 결과이므로 특정 RTL 파일 전체를 단독 작성했다고 표현하지 않는다.

최종 패키지는 다른 위치에 복사해도 스크립트 기준 상대 경로로 test_one과 test_all을 실행하도록 정리했다. bitstream, XSA, host runner, prepared dataset, RTL snapshot과 reports를 함께 남겨 단순 발표 영상이 아니라 다시 실행 가능한 보드 검증 근거를 만들었다. 프로젝트는 AIX 2026 Deep Learning Hardware 설계경진대회에서 장려상을 수상했다.
