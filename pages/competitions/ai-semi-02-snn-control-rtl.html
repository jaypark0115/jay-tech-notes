2. 위치 오차가 네 방향 스파이크가 되는 과정

이 회로에는 현재 공의 X·Y 위치와 속도 크기가 들어옵니다. 먼저 중앙과의 오차를 네 방향의 양수 값으로 바꾸고, 방향마다 하나씩 배치한 LIF 뉴런이 그 값을 시간에 따라 누적합니다. 스파이크가 발생한 채널은 어떤 방향의 모터가 반응해야 하는지를 나타냅니다. 다만 출력은 모터 드라이버의 pulse width가 정해진 구동 파형이 아니라, 클록마다 갱신되는 1-bit 방향 이벤트입니다.

error_encoder: signed 오차를 네 방향 크기로 변환

LIF 뉴런에는 한 방향의 자극 크기만 전달하는 편이 이해하기 쉽습니다. 그래서 X와 Y를 그대로 넣지 않고, 값의 부호에 따라 해당하는 방향만 활성화합니다. 예를 들어 X가 양수라면 X축의 한쪽 채널에는 그 절댓값이 들어가고 반대쪽 채널은 0이 됩니다.

error_encoder.v · 방향과 크기를 만드는 핵심 부분 
wire signed [W_IN-1:0] ex = -x;
wire signed [W_IN-1:0] ey = -y;

assign X_x_pull = (ex > 0) ? (ALPHA * ex) : 0;
assign X_x_push = (ex < 0) ? (ALPHA * (-ex)) : 0;
assign X_y_pull = (ey > 0) ? (ALPHA * ey) : 0;
assign X_y_push = (ey < 0) ? (ALPHA * (-ey)) : 0;

이 변환 뒤에는 모든 채널이 0 이상의 크기를 갖습니다. 각 뉴런이 부호 판정까지 반복하지 않아도 되고, X축과 Y축의 네 방향을 같은 방식으로 처리할 수 있습니다. 전체 연결은 error_encoder.v에서 확인할 수 있습니다.

입력 한 세트를 실제 RTL 식으로 따라가기

x=+8, y=−3, v_abs_x=v_abs_y=2를 넣으면 encoder 내부 오차는 ex=−8, ey=+3입니다. 기본 ALPHA=1에서 네 방향 입력은 아래처럼 정해집니다.

채널Encoder 출력의미
X_PULL0X축 pull 뉴런에는 위치 자극 없음
X_PUSH8X축 push 뉴런에 오차 크기 8 전달
Y_PULL3Y축 pull 뉴런에 오차 크기 3 전달
Y_PUSH0Y축 push 뉴런에는 위치 자극 없음

보관된 RTL의 기본 LIF 파라미터는 LEAK=10, U_THR=2000, W_GAIN=1, K_V=20입니다. 코드가 구현한 상태식은 다음과 같습니다.

spike[t+1] = (U[t] > 2000)
U[t+1] = 0, if U[t] < 10
U[t+1] = U[t] − 10 + X_in[t] − 20·v_abs[t] − (spike condition ? 2000 : 0), otherwise

코드 대조에서 발견한 제한 현재 lif_neuron.v는 reset 직후 U=0에서 U < LEAK 분기로 들어가 입력을 더하지 않으므로, 이 파라미터와 초기 조건에서는 막전위가 0에 머뭅니다. 15g·30g 실험은 별도의 Baby_Neuron_Core 기반 네트워크 코드에서 수행됐습니다. 따라서 그 실험 결과를 이 단순 output-layer snapshot의 동작 증명으로 사용하지 않습니다.

lif_neuron: 누적·누설·임계값 발화

LIF(Leaky Integrate-and-Fire)의 의도는 막전위에 입력을 누적하고, 누설 항으로 상태를 낮추며, 임계값을 넘으면 spike를 만든 뒤 임계값만큼 빼는 것입니다. 아래 코드는 그 구조를 담고 있지만, 앞의 수치 추적처럼 U < LEAK 분기에서 입력까지 건너뛰는 초기 상태 문제가 남아 있습니다.

lif_neuron.v · 누적, 임계값 판정과 리셋 
spike <= (U > U_THR);

if (U < LEAK) begin
  U <= 0;
end else begin
  U <= U - LEAK
       + (W_GAIN * X_in)
       - ((U > U_THR) ? U_THR : 0)
       - (K_V * v_abs);
end

방향 오차 X_in은 막전위를 올리고, 속도 크기 v_abs는 계수 K_V와 함께 막전위를 낮추는 항에 들어갑니다. 설계 의도상 위치 오차가 클수록 발화를 밀어 올리고, 속도가 큰 동안에는 반응을 누르는 형태입니다. 상태 갱신 코드는 lif_neuron.v에 있습니다.

controller_top: 동일한 LIF 모듈을 네 방향에 연결

top 모듈은 encoder가 만든 네 값을 같은 LIF 모듈 네 개에 연결합니다. generate 구문을 사용해 뉴런 구조와 파라미터는 공유하고, 각 인스턴스가 담당하는 방향만 달라집니다. 이렇게 만든 네 스파이크가 X pull, X push, Y pull, Y push 출력이 됩니다.

controller_top.v · 같은 뉴런 구조를 네 방향에 연결 
for (i = 0; i < 4; i = i + 1) begin : SNN_CHANNEL
  lif_neuron u_lif (
    .X_in(X_in[i]),
    .v_abs(v_abs[i]),
    .spike(spikes[i])
  );
end

assign motor_X_PULL = spikes[0];
assign motor_X_PUSH = spikes[1];
assign motor_Y_PULL = spikes[2];
assign motor_Y_PUSH = spikes[3];

top-level의 포트와 실제 배선은 controller_top.v에서 이어서 볼 수 있습니다.

현재 코드가 설명하는 범위

이 RTL은 위치·속도 숫자가 이미 준비됐다고 가정하고, 네 방향 제어 스파이크를 만드는 부분을 설명합니다. 실제 장치에 연결하려면 센서 값을 좌표로 바꾸는 전처리, 모터 드라이버가 요구하는 pulse width, 반대 방향 동시 활성화를 막는 보호 로직과 기구부의 지연을 추가로 다뤄야 합니다. 따라서 이 코드는 전체 BallControl 장치가 아니라 출력 제어 파이프라인의 구현 근거로 읽는 것이 정확합니다.

이 단계에서 한 일

encoder, LIF와 top-level 사이의 데이터 폭과 방향 순서를 맞추고, 네 채널을 같은 모듈로 연결해 출력 계층을 구성했습니다. 또한 실제 Verilog와 발표자료의 블록도가 같은 신호 흐름을 설명하도록 정리했습니다.
